# KeyPort 界面设计系统

> 控制室方向 · 深色单主题 · 面向自托管运维者的监控面板
>
> 色板来源：ui-ux-pro-max 技能库（slate 深阶 + 绿色强调），产品类型判定
> 为 Enterprise dashboard。所有对比度经 WCAG 公式实算，非目测。

## 方向与质感

**是谁**：自托管的开发者/运维者，面板常驻第二屏。要回答「池子健康吗 / 什么坏了 / 我在烧多少额度」。

**质感**：基础设施仪表盘。冷静的表面、精确的数字、克制的颜色、值得细看的密度。
参考系是 Grafana / Linear / Vercel，不是 shadcn 模板。

**不做**：浅色主题、渐变、发光作为主要可供性、装饰性动画。

## 色彩（token 语义）

Token 按产品世界命名，读一遍就知道是什么产品：机架、指示灯、计量表。

| Token | 值 | 十六进制 | 含义 |
|---|---|---|---|
| `--surface` | `228 84% 4.9%` | `#020617` | 页面底（机箱内壁） |
| `--panel` | `228 43% 9.6%` | `#0E1223` | 卡片/面板（机架单元） |
| `--rail` | `222 47% 8.4%` | `#0B1120` | 侧边导航轨道 |
| `--well` | `228 29% 14.3%` | `#1A1E2F` | 凹陷区（表格头、输入底） |

| `--edge-strong` | `215 19% 34.5%` | `#475569` | 强调边框/分隔 |

**对比度实算矩阵**（WCAG AA 正文阈值 4.5:1，非文本 UI 3:1）：

| 前景 | surface | panel | well | rail |
|---|---|---|---|---|
| `--ink` | 19.28 | 17.77 | 15.80 | 18.00 |
| `--ink-dim` | 13.59 | 12.52 | 11.13 | 12.68 |
| `--ink-faint` | 7.87 | 7.25 | 6.45 | 7.34 |
| `--signal` | 8.85 | 8.16 | 7.25 | 8.26 |
| `--caution` | 12.08 | 11.14 | 9.90 | 11.28 |
| `--fault` | 7.29 | 6.72 | **5.97** | 6.81 |
| `--live` | 11.16 | 10.29 | 9.14 | 10.42 |

最低组合 5.97:1，全部达标。`--on-signal` 压在 `--signal` 上为 7.83:1。

> 技能库原方案的 `--fault: #EF4444` 在 `--well` 上仅 4.39:1，未达 AA，
> 因此上调为 `#F87171`。`#F8FAFC` 白字压绿仅 1.9:1，故主按钮必须用
> `--on-signal` 深底，不能用 `--ink`。

**规则**：
- 一屏一个主强调色（`--signal`）。`--caution` / `--fault` 只表达状态，不做装饰。
- 层级用发丝边框（`--edge`），不用阴影。
- 指示灯允许 6px 光晕（`box-shadow`），这是唯一的光效——它模拟真实的指示灯。

## 字体

- **界面文字**：`IBM Plex Sans`（next/font 自托管，`--font-sans`），回落 `ui-sans-serif / PingFang SC / Microsoft YaHei`。
- **数据/标识**：`JetBrains Mono`（next/font 自托管，`--font-mono`）—— 所有数字、ID、密钥前缀、模型名、CIDR、时间。
- 所有数字加 `tabular-nums`；mono 另开 `zero` 特性（0 带斜杠，与 O 区分）。
- 只下载 latin 子集：中文由系统字体承接，避免每个字重数 MB。
- 标题不加 `letter-spacing`；仅全大写小标签用 `0.06em`。

## 尺度

| 项 | 值 |
|---|---|
| 间距基数 | 4px（Tailwind 默认刻度） |
| 圆角 | `--radius: 6px`（面板）/ 4px（控件）/ 3px（标签） |
| 字号 | 标签 10-11px · 正文 12-13px · 标题 15-18px · KPI 20-22px |
| 面板内边距 | 14px |
| 表格行高 | 32px（紧凑） |
| z-index 层级 | `--z-dropdown: 30` / `--z-modal: 40` / `--z-toast: 50`（固定，无任意值） |

## 签名元素

**账号状态轨**（`AccountRail`）——侧边栏底部常驻，每个账号一盏灯。
像配线架：一眼扫完整个池子，灯色即状态，悬停出额度。

**配额液位**（`Meter`）——把配额渲染成细长液位条 + 等宽数字，像油量表而非纯文本。

## 状态约定

- **空态**：必须给一个明确的下一步动作（不能只写"暂无数据"）。
- **加载**：结构性骨架屏，不用 spinner。
- **错误**：显示在触发操作的位置旁边，不用全局 toast 顶替。
- **破坏性操作**：`AlertDialog` 二次确认（不用 `window.confirm`）。
- **图标按钮**：必须有 `aria-label`。

## 已知偏离（技术债）

- 图标按钮的 `aria-label` 需全量补齐（本轮随改动文件补）。
- 键盘焦点行为目前用原生元素，未引入 Base UI / Radix。
